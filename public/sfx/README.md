# Bullshit Factory sound effects

## Bork bark

`dog_bark.wav` is a normalized WAV conversion of [George vuf 1996.ogg](https://commons.wikimedia.org/wiki/File:George_vuf_1996.ogg), a single dog-bark recording by Broadbeer released into the public domain. The conversion changes only the container/sample format and applies a light speech-safe high/low-pass filter and loudness normalization for the episode mix.

The previous generated tone/noise cue is retained on `.76` as `dog_bark.synthetic-v1.wav` for rollback only and is not used by production.
